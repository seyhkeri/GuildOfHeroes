## Собственный проект

Тема проекта: Каталог компьютерных игр

Главный класс: Game

Почему этот объект нужен программе:
Этот объект является основой каталога игр. Он позволяет объединить все ключевые характеристики конкретной игры (название, жанр, год и рейтинг) в одну сущность, чтобы удобно управлять библиотекой игр, выводить их списком и сортировать.

Какие данные хранит объект:

Title (строка) - Название игры
Genre (строка) - Жанр игры
ReleaseYear (целое число) - Год выхода игры
Rating (вещественное число) - Пользовательский рейтинг игры

Какие значения задаются через конструктор:
Через параметры конструктора передаются обязательные фундаментальные свойства игры, без которых её существование в каталоге не имеет смысла: название (title) и жанр (genre).

Какие значения можно задавать автоматически:
Автоматически задаются текущий год (в качестве года выпуска по умолчанию для ожидаемых новинок) и начальный нулевой рейтинг для только что добавленной в систему игры.

## Дополнительное задание

Какое значение я решил задавать автоматически и почему?
Я решил автоматически задавать поле Rating = 0.0 внутри конструктора. 

Это логично, так как при добавлении абсолютно новой игры в каталог у неё ещё нет оценок от пользователей. Автоматическое присвоение избавляет от необходимости вручную передавать 0.0 каждый раз при создании объекта (new Game("Название", "Жанр")), защищает от случайных ошибок и делает код чище.
